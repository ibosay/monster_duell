# Monster-Duell

Monster-Duell ist ein deutsches Kartenspiel im Browser: Du beschwörst Monster in eine 3D-Arena, fusionierst sie zu stärkeren Kreaturen und zerstörst den Kristall deines Gegners. Du kannst gegen den Computer spielen oder zu zweit am selben Gerät.

Die 3D-Version (`index.html`) ist eine einzelne HTML-Datei mit eingebettetem Three.js. Unterstützt das Gerät kein WebGL, führt ein Link zur klassischen 2D-Version (`2d.html`).

Die animierten 3D-Monster stammen von [Quaternius](https://quaternius.com) und stehen unter CC0 1.0. Der Goblin ist das Meshy-Modell „Goblin“ von lionnik2013 (CC0, https://www.meshy.ai/3d-models/goblin-019d6dd2-556a-79af-83df-8308aba33c57). Alle Quellen und Lizenzen stehen in `CREDITS.md`, `assets/LICENSES.md` und `THIRD_PARTY_LICENSES.txt` (Three.js und meshoptimizer, MIT).
